LIVE CHROME BRIDGE

Connect Your Actual Chrome Tab Groups (10-Second Setup)

Because of Chrome's browser security sandbox, a localhost web page cannot read your real tabs directly without a browser extension. We included a lightweight bridge extension in this project!

  1. Open chrome://extensions in a new Chrome tab.
  2. Toggle on Developer mode (top-right corner).
  3. Click Load unpacked (top-left) and select the chrome_extension folder inside this repository:
    ./chrome_extension
  4. Refresh this page and click 🔄 Sync My Chrome Tabs!
CLOSED SAVED TAB GROUPS

Import Closed Tab Groups from Chrome Profile

Chrome's extension API (chrome.tabGroups) only exposes currently open tab groups. Closed "Saved Tab Groups" are stored by Chrome in your profile's Sync Data/LevelDB folder.

  1. Option A (Automatic): Run python3 app.py directly in your own terminal—clicking 🔄 Sync My Chrome Tabs will automatically read ~/.config/google-chrome/*/Sync Data/LevelDB!
  2. Option B (Select Folder Here): Click Select LevelDB Folder below and choose:
    ~/.config/google-chrome/Default/Sync Data/LevelDB
